# Messenger App — Проект Яндекс.Практикум

Учебный проект по разработке веб-мессенджера. В течение 4-х спринтов создается полноценное приложение с использованием современных инструментов фронтенд-разработки.

## Спринт 1: Статическая верстка и архитектура

На текущем этапе реализована статическая верстка основных страниц, настроена сборка проекта и архитектура стилей.

### Реализованные страницы:

- **Главная (`/`)** — список всех созданных страниц.
- **Авторизация и Регистрация** — формы входа и создания аккаунта.
- **Мессенджер** — основное рабочее пространство:
  - Левая панель со списком чатов и кнопкой-бургером (переход в профиль).
  - Область чата с лентой сообщений и полем ввода.
  - Функционал прикрепления изображений (base64) и ввода текста.
  - Выпадающее меню управления чатом (добавление/удаление участников).
- **Профиль пользователя** — страница просмотра данных:
  - Редактирование профиля (включая смену аватара через `Base64`).
  - Смена пароля.
- **Страницы ошибок** — страницы для кодов 403, 404, 500.

### Текущие ограничения (Logic status):

- **Данные:** Вся информация на страницах является статической («рыба»).
- **Формы:** Кнопки отправки форм не активны.
- **Хранение:** Изменения аватара и сообщений в чате работают без сохранения и сбрасываются при перезагрузке.

## Технологический стек

- **Vite** — инструмент сборки проекта.
- **Handlebars** — шаблонизатор для генерации HTML-компонентов.
- **Sass (SCSS)** — препроцессор для стилей (использована архитектура с разделением на Helpers, Blocks и Globals).
- **TypeScript** — строгая типизация всей логики приложения.
- **BEM (БЭМ)** — методология именования классов.

## Установка и запуск

1.  **Установка зависимостей:**

    ```bash
    npm install
    ```

2.  **Запуск в режиме разработки:**

    ```bash
    npm run dev
    ```

3.  **Сборка и запуск продакшн-версии (на порту 3000):**
    ```bash
    npm run start
    ```
    _Команда выполняет проверку типов `tsc`, собирает проект в папку `dist` и запускает локальный сервер для предпросмотра._

## Архитектура (кратко)

- `/src/styles` — стили (Sass), разделенные по назначению.
- `/static` — папка с Handlebars-шаблонами (страницы и компоненты).
- `/public` — статические ресурсы (изображения, фавиконы), попадающие в сборку напрямую.
- `/screenshots` — снимки экрана с текущим прогрессом верстки.
